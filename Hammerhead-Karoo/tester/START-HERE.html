Scout for Karoo: beta test

Version @VERSION@ · thank you for testing!

This sheet has your download link, the test rides and what to send back. Everything else (setup, the tiles, troubleshooting) is in MANUAL.html in this package.

This is an early test on a real Karoo. Things may break, and that's exactly what we want to find out. A crash or something odd is a useful result. Just note what you were doing when it happened.

1. Install and set up

Follow MANUAL.html sections 1–3: what you need, install, and adding the Scout page to your ride profile. For the install you need this version's download link:

  • Karoo 3 (Companion app): open Scout @VERSION@ APK on your phone and share it to Hammerhead Companion. Use the link, not the file inside the zip. To type or paste it:
    @APK_URL@
  • Karoo 2 or USB: adb install -r scout-karoo-@VERSION@.apk from the folder with this package.

Give the Scout field a page of its own, so it shows the tag tiles.

2. Test rides (about 15 minutes each)

Start and stop the ride on the Karoo as usual. Scout follows along by itself.

Ride A: recording without tagging

  1. Start a ride. For the first few minutes, stay on a page without the Scout field.
  2. If you have a radar, ride somewhere cars pass you.
  3. Swipe to the Scout page and check that it shows RECORDING, a tag count, and a radar line (e.g. no radar or 3 cars).
  4. End and save the ride.

Ride B: tagging

  1. Start a ride and swipe to the Scout page.
  2. Tap a few tiles. Does the tile light up and the count go up? If tapping does nothing, use the Tag ride bonus action or the Scout app's Open tagging instead, and tell us.
  3. Beeps: do you hear a beep on every tag? Try once with the Karoo's sounds turned off too, and tell us whether it still beeps.
  4. Choices: tap NOTICE, pick an option, then swipe to another page straight away. The tag should still be saved (the count goes up).
  5. Undo: tap OTHER, then tap it again within 3 seconds. You should hear a different, two-tone beep and the count goes back down.
  6. Surface: tap SURFACE and pick one. Ride a bit, then end the stretch with the red END strip at the bottom.
  7. Go back to your normal pages, ride a bit, end the ride.

Ride C: radar car count (if you have a radar)

  1. Ride a road with some traffic and roughly count the cars that overtake you.
  2. At the end, compare your count with the cars number on the Scout page.

3. What to send back

  • Karoo model (2 or 3) and Karoo software version (shown in the Karoo settings).
  • Ride B: did taps on the Scout page work, and did it beep with sounds on and with sounds off?
  • For each ride: radar yes/no, roughly how many tags you made, and, for Ride C, your car count and Scout's.
  • The ride .fit files. Get them from the Hammerhead dashboard (export activity), a service you sync to, or over USB.
  • Anything odd: crashes, a Scout page that says to start a ride while you're riding, missing beeps, a frozen screen. Photos of the Karoo screen help a lot.
